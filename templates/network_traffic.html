Como Configurar seu Firewall Físico / Virtual para Enviar Syslog ao Cortex

Aponte o envio de Syslog do seu firewall para o IP deste servidor na porta UDP 1514. O Cortex decodificará os cabeçalhos de conexão e cruzará automaticamente IPs de origem e destino com a base de inteligência de ameaças. 

# FortiOS CLI
config log syslogd setting
    set status enable
    set server "<IP_DO_CORTEX>"
    set mode udp
    set port 1514
    set facility local7
end
# pfSense / OPNsense WebGUI:
Status > System Logs > Settings > Remote Logging Options
1. Marque: "Enable Remote Logging"
2. Remote log servers: <IP_DO_CORTEX>:1514
3. Remote Syslog Contents: Marque "Firewall Events"
4. Salve e aplique.
# MikroTik RouterOS Terminal
/system logging action add name=cortex-syslog target=remote remote=<IP_DO_CORTEX> remote-port=1514
/system logging add action=cortex-syslog topics=firewall,info
# Cisco ASA / IOS CLI
logging enable
logging host inside <IP_DO_CORTEX> udp/1514
logging trap informational
logging facility 23
# Linux /etc/rsyslog.d/50-cortex.conf
*.* @<IP_DO_CORTEX>:1514

# Reiniciar serviço
sudo systemctl restart rsyslog
